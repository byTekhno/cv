Начинающий Manual QA с практикой на учебных проектах и полной тестовой документацией в GitHub. Уверенно работаю с тест-кейсами, чек-листами и баг-репортами, применяю техники тест-дизайна. Ключевые навыки

Тестирование: ручное функциональное (web, мобильный веб); smoke; регрессионное; сквозное (E2E); альфа- и бета-тестирование. Нефункциональное: юзабилити, совместимость (базовый уровень). Уровни (теория): модульное, интеграционное, системное, приёмочное. Подходы: black box; white box (теория). Анализ требований и построение тестового покрытия. Оформление дефектов: steps to reproduce, expected/actual, severity / priority.
Тест-дизайн: Equivalence Partitioning · Boundary Value Analysis · Decision Table Testing · Pairwise Testing · State Transition Testing
Документация: тест-кейсы · чек-листы · баг-репорты · отчёты о прогонах (test runs)
Инструменты: DevTools · Jira (учебный проект) · Qase · TestIT · Git / GitHub
Платформы: Web · мобильный веб (реальное устройство iPhone / Safari)
Языки: русский — родной; английский — A2 (чтение документации, интерфейсов, учебных материалов)
