### 2. Internet Bank QA (учебный проект курса Test Grow)

**Ссылка:** https://github.com/byTekhno/testgrow-internet-bank-qa  
**Тип:** учебное тестирование финтех-подобного стенда (интернет-банк)  
**Стек практики:** требования, тест-план, тест-кейсы, тест-данные, test runs, bug reports

**Что сделал:**

- Провёл smoke-прогон: **Pass 3 / Fail 2**
- Выполнил полный прогон: **Pass 22 / Fail 10 / Blocked 3 / Skipped 3**
- Оформил баг-репорты **BUG-001 … BUG-008** (лимиты и границы сумм переводов, отображение счетов, фильтры)
- Собрал тест-кейсы по модулям: авторизация, меню, список счетов, детали счёта, перевод, регресс
- Зафиксировал ТЗ, составил тест-план и подготовил тестовые данные
- Прошёл полный цикл тестовой документации: требования → тест-план → кейсы → прогоны → дефекты
- Разобрал сценарии, близкие к банковским пользовательским путям (учебная практика, не коммерческий продукт)

**Почему проект важен:** помогает переносить навыки ручного QA на домен, где важны точность сценариев, аккуратность в данных и понятная фиксация дефектов.
