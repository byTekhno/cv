## Ключевые навыки

### Тестирование

- Ручное функциональное тестирование (web, мобильный веб)
- Виды: smoke, регрессионное, сквозное (E2E), альфа- и бета-тестирование
- Нефункциональное тестирование: юзабилити, совместимость (базовый уровень)
- Уровни тестирования (теория): модульное, интеграционное, системное, приёмочное
- Подходы: black box; white box (теория)
- Анализ требований и построение тестового покрытия
- Оформление дефектов: steps to reproduce, expected/actual, severity / priority

### Тест-дизайн

- Equivalence Partitioning
- Boundary Value Analysis
- Decision Table Testing
- Pairwise Testing
- State Transition Testing

### Тестовая документация

- Тест-кейсы
- Чек-листы
- Баг-репорты
- Отчёты о прогонах (test runs)

### Инструменты

- DevTools
- Jira (учебный проект)
- Qase
- TestIT
- Git / GitHub

### Платформы

- Web
- Мобильный веб: реальное устройство iPhone / Safari

### Языки

### 3. Mobile QA — iPhone / Safari

**Ссылка:** https://github.com/byTekhno/mobile-qa  
**Тип:** учебное ручное тестирование мобильного веба на реальном устройстве  
**Объект:** saucedemo.com в Safari на iPhone 11 (iOS 27.0.1)  
**Стек практики:** мобильный чек-лист, test run, скриншоты, сравнение с десктопом

**Что сделал:**

- Составил мобильный чек-лист на 37 проверок: смоук + экран и вёрстка, ввод и клавиатура, навигация, прерывания и сеть
- Выполнил прогон на реальном iPhone: **Pass 36 / Fail 0 / Blocked 1**
- Проверил поворот экрана посреди checkout, экранную клавиатуру, свайп «назад» после Logout, iOS-пикер, приватную вкладку, сворачивание Safari, авиарежим и слабую сеть
- Отделил мобильные дефекты от особенностей сайта: каждое подозрение сверял с десктопом на ширине 375px
- Зафиксировал наблюдение: в авиарежиме заказ «оформляется» без ошибки, так как сайт клиентский; в реальном магазине это был бы критичный дефект

**Результат:** новых дефектов на iPhone не найдено, подтверждён известный дефект `visual_user`; результаты задокументированы со скриншотами.
